How DVM uses this list

    
  
  • Lockdown off (system.radio_id.acl: false): every radio may talk except IDs listed here as Blocked.
    • 
  
  • Lockdown on (acl: true): only IDs listed here as Allowed may talk/register — anything not on the list is refused.
    • 
  
  • dvmhost and dvmfne re-read rid_acl.dat every system.radio_id.time minutes, so list edits apply without a restart. Turning lockdown on/off changes config.yml, which dvmhost only reads at start-up, so it needs a restart.
    • 
  
  • On a trunked system the control Pi keeps the list and copies it to every voice-channel Pi automatically.
    • 
  
  • Format (from dvmhost's rid_acl.example.dat): RID,Enabled(1/0),Alias,IP, — commas aren't allowed in names.

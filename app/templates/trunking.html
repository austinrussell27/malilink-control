Trunking & voice channels coming next

Design preview. One Pi runs the control channel (and the network hub); every extra Pi joins as a voice channel with a short pairing code over Tailscale.

On the control-channel Pi

  1. Click Create pairing code.
  2. Code is valid for 10 minutes, single use.
  3. The control Pi assigns the next channel number, adds the Pi to its voice-channel list and to this dashboard.

On a new Pi: "Add a voice channel"

Its Tailscale name or 100.x.y.z address.

  




Pairing API


POST /api/pairing/codes            (control)  -> {code, expires}
POST /api/pairing/claim  {code,name,url,rpc_address,rpc_port}  (control, called by the new Pi)
                                            -> {channelId, channelNo, site{...}, controlCh{...}, network{...}, cluster_key, todo[]}
POST /api/pairing/join   {control_url, code}  (new Pi)  -> calls /claim, stores the bundle, role=voice
GET  /api/pairing/voice-channels    (control)  -> paired voice channels
GET  /api/local/snapshot | /api/local/logs   (every Pi; header X-Malilink-Cluster-Key) -> dashboard aggregation

Install the DVM software

Downloads and builds dvmhost and dvmfne from github.com/DVMProject/dvmhost, installs them to /usr/local, creates the dvmhost user and installs the systemd services. Safe to run again to update. On a Pi 5 the build takes roughly 15–30 minutes.

    System IDs

    The NAC is like a "tone" for P25 — your radios must use the same one. Defaults are fine for a single site.

    3 hex digits, e.g. 293. Avoid F7E/F7F (special "receive any" values).
    Advanced (only matters for trunking / multi-site)
